04 / Algorithm 1

Finding Mutual Friends (Nested Loops)

How common friends are calculated without graph intersections.

// Time Complexity: O(F1 × F2)
public ArrayList<String> getMutualFriends(String u1, String u2) {
    ArrayList<String> mutual = new ArrayList<>();
    User user1 = findUser(u1);
    User user2 = findUser(u2);

    for (String f1 : user1.getFriends()) {
        for (String f2 : user2.getFriends()) {
            if (f1.equalsIgnoreCase(f2)) {
                mutual.add(f1);
                break;
            }
        }
    }
    return mutual;
}

The outer loop takes Priya, inner loop finds Priya in Nisha's list → Match!

05 / Algorithm 2

Friend Suggestions ("Friends of Friends")

2-hop recommendation logic using simple loops and conditions.

1. Loop Direct Friends

For user U, iterate through each direct friend F in U.getFriends().

2. Loop FoF Candidates

For each F, inspect their friends Candidate in F.getFriends().

3. Filter & Sort

Ensure Candidate != U and !U.isFriend(Candidate). Sort by mutual count via Bubble Sort.

💡 Real Demo Outcome: For user Rahul, his friend is Priya. Priya is friends with Nisha and Karan. Neither is a friend of Rahul yet. The system recommends both Nisha & Karan with badge: "🤝 Connected via Priya".

06 / Statistical Insights

Basic Network Analysis

Calculating structural metrics through single-pass linear loops.

Total Users

Size of the user list: users.size().

Friendships

Sum of all friend counts divided by 2: totalDegrees / 2.

Most Popular

User with max(friendCount) via linear max scan loop.

Isolated Count

Users with 0 friends: friendCount == 0.

Formula Proof: Why Divide by 2?

Because every friendship is mutual, if User A is friends with User B, both store each other's name. Thus, summing the lengths of all friend lists counts every connection exactly twice. Hence, Total Unique Friendships = Total Degrees / 2.

08 / Examination Readiness

College Viva Questions & Model Answers

Common questions examiners ask during project evaluation.

Q1: Why did you not use Graph BFS/DFS?

"Our syllabus is restricted to Trees. Instead of forcing heavy graph structures, we demonstrated how pure OOP encapsulation (User class with internal ArrayList) and linear loops solve network suggestions cleanly and transparently."

Q2: How are duplicate friendships avoided?

"Before adding, user1.isFriend(user2) runs a linear check. Also, self-friendship is blocked with if (u1.equalsIgnoreCase(u2)) return false;."

Q3: What is the time complexity of suggestions?

"It is O(D × F), where D is the target user's direct friends count and F is the average friend count of each friend, followed by an O(K²) Bubble Sort for ranking K suggestions."

Q4: How does it communicate with the web frontend?

"Java's built-in HttpServer serves REST API JSON endpoints (/api/network, /api/mutual, /api/user) consumed via JavaScript fetch()."
